### Animations

Pour les animations, je vais principalement utiliser  **JavaScript**. Ce choix correspond bien à mon concept inspiré de l'interface de la PlayStation 3.

Je veux notamment animer les éléments du menu lors du **survol**, du **clic** et du changement de section. Les animations permettront de donner l'impression de naviguer dans une interface de console plutôt que dans un site web traditionnel.

### Structure de navigation

J'ai choisi une structure **one-page**. Le portfolio sera présenté comme une interface de menu de PlayStation, avec différentes sections accessibles à partir de la navigation.

Ce choix correspond à mon concept, car l'utilisateur pourra naviguer entre mes projets, mes compétences et mes informations comme s'il parcourait les différentes catégories d'un menu de console.
